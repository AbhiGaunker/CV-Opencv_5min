# CV-Opencv_5min

This repository contains small projects developed during my learning phase with the OpenCV library. Each project focuses on a specific aspect of computer vision, implemented using Python and OpenCV.

## Projects Included

1. **Body Detection**
   - **Description**: Detects human bodies in images or video streams.
   - Used in self-Driving Cars to identify pedestrians, sirvelience camera for security purpose, and also crowd Analytic 
   
2. **Face and Eye Detection**
   - **Description**: Identifies faces and eyes within images using pre-trained classifiers.
   - User verification and Vr interaction (Apple VR uses eyes to tract where you are looking and to select it) And also in driver sleep analysis while driving.

3. **Handwritten Digits Recognition**
   - **Description**: Recognizes handwritten digits using machine learning models trained on datasets like MNIST.
   - Usefull in Postal Services for Sorting mail by reading handwritten zip codes. And Digitizing handwritten forms into electronic records.

4. **Object Tracking Using HSV**
   - **Description**: Tracks objects in videos based on their color using the HSV color space.
   - In Sports Analytics for Monitoring players or equipment during games. And also in Robotics Enabling robots to follow colored paths or objects.

5. **Road Line Detection**
   - **Description**: Detects lane lines on roads, useful for autonomous driving applications.
   - Used in Autonomous Vehicles for Recognizing lane boundaries for safe navigation.
